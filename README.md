# K10 Drink Picker

日月光高雄 K10 上班飲料決策器。這是一個無後端的靜態前端網頁，整理 K10 附近可在 Foodpanda 或 Uber Eats 公開頁面查到的楠梓飲料店，讓上班時可以快速抽一家、依心情篩選、保存愛店和記錄最近喝過的店。

## 功能

- 依平台、心情、預算、多人團訂、避開咖啡因篩選
- 預設顯示完整可核對候選，避免新加入店家被預算或團訂篩選藏起來
- 依參考營業時間與接單緩衝計算「只看高把握營業中」
- 只看近期優惠候選，例如平台新客優惠、折扣券或買一送一線索
- 顯示優惠項目內容，例如指定品項折扣、外送費優惠與品牌券線索
- 今日推薦與重新抽籤
- 最近新開店家專區，清楚區分真正的新開店與補回的既有分店
- 店家可依推薦、新開、評分或預算排序，並可一鍵只看新店或重設條件
- Foodpanda / Uber Eats 店家連結
- 愛店與最近喝過紀錄，使用瀏覽器 localStorage
- 店家資料更新區：可回報新店/歇業/優惠異動，也可匯出與匯入本機 JSON
- 支援手機與桌面版
- 深色模式

## 資料說明

資料整理日期：2026-07-30。

K10 地址以公開 AED 場所資料中的「日月光半導體製造股份有限公司K10廠區，高雄市楠梓區中一街5號」為定位基準。店家候選依 Foodpanda、Uber Eats 公開頁面與 K10 使用者實測回報整理；每間內建候選都必須附可核對的 Foodpanda 或 Uber Eats 外送頁。營業狀態依整理到的參考營業時間在前端即時計算，並保留剛開店與快打烊的接單緩衝；近期新增或時間未穩定的店家會標成「查平台」，不直接算作高把握營業中。外送範圍、店家暫停接單、營業時間、外送費和優惠會因平台定位與時間變動，下單前請以平台 App 即時狀態為準。

優惠候選不是保證當下可用，而是把近期公開頁面或品牌優惠資訊中看到的折扣線索標出來，方便上班前優先檢查。

GitHub Pages 是靜態網站，無法安全地在瀏覽器中直接寫回 repository。若要讓所有人都看到資料更新，請使用網頁上的 GitHub issue 回報入口，或修改店家 JSON 後送 PR。新增店家時請附直接外送店家頁；搜尋頁或只有口頭回報的店家先不納入主要候選。

## 本地開啟

直接用瀏覽器開啟 `index.html` 即可。

也可以啟動一個簡單靜態伺服器：

```bash
python3 -m http.server 4173
```

## 部署

專案包含 GitHub Pages workflow，推到 GitHub 後可使用 GitHub Actions 部署靜態頁面。
