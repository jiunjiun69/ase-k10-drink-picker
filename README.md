# K10 Drink Picker

日月光高雄 K10 上班飲料決策器。這是一個無後端的靜態前端網頁，整理 K10 附近可在 Foodpanda 或 Uber Eats 公開頁面查到的楠梓飲料店，讓上班時可以快速抽一家、依心情篩選、保存愛店和記錄最近喝過的店。

## 功能

- 依平台、心情、預算、多人團訂、避開咖啡因篩選
- 依公開營業時間即時計算「只看營業中」
- 只看近期優惠候選，例如平台新客優惠、折扣券或買一送一線索
- 顯示優惠項目內容，例如指定品項折扣、外送費優惠與品牌券線索
- 今日推薦與重新抽籤
- Foodpanda / Uber Eats 店家連結
- 愛店與最近喝過紀錄，使用瀏覽器 localStorage
- 支援手機與桌面版
- 深色模式

## 資料說明

資料整理日期：2026-05-02。

K10 地址以公開 AED 場所資料中的「日月光半導體製造股份有限公司K10廠區，高雄市楠梓區中一街5號」為定位基準。店家候選依 Foodpanda、Uber Eats 公開頁面整理；營業中依整理到的公開營業時間在前端即時計算。外送範圍、店家暫停接單、營業時間、外送費和優惠會因平台定位與時間變動，下單前請以平台 App 即時狀態為準。

優惠候選不是保證當下可用，而是把近期公開頁面或品牌優惠資訊中看到的折扣線索標出來，方便上班前優先檢查。

## 本地開啟

直接用瀏覽器開啟 `index.html` 即可。

也可以啟動一個簡單靜態伺服器：

```bash
python3 -m http.server 4173
```

## 部署

專案包含 GitHub Pages workflow，推到 GitHub 後可使用 GitHub Actions 部署靜態頁面。
